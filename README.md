# VELMORA

A travel poster for Velmora, an invented coastal place built around a single spiral terraced lighthouse above a calm turquoise bay. Golden-hour light, warm clouds and small sailboats carry the eye from the name in the sky down to the beacon and out to the horizon. The bundled program copies the finished poster image to the output directory.
